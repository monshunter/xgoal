# BUG-001：中文模板混入英文标题和未解析变量

> 这是完整 Bug 记录样例。真实记录必须使用当前故障的复现结果、代码位置和验证证据。

## 现象与影响

安装后的 `.autogo/templates/` 中同时出现中文、英文标题，并保留标题、日期等双花括号变量。Agent 只读取模板时无法判断最终文档应是什么样子。

影响范围包括所有依赖这些模板创建 Plan、Spec、Review 和运维记录的工作流。

## 时间线与复现

1. 安装 AutoGo Harness。
2. 打开 `.autogo/templates/documents/adr.md.tmpl`。
3. 可以看到英文小节和未解析变量，且文件本身没有完整示例内容。

## 根因与促成因素

根因是把“供 Agent 理解的参考资料”误建模成“供脚本渲染的文本片段”。校验又以变量和 Front Matter 字段为标记，进一步固化了这种设计。

## 修复

- 将模板改为固定路径的完整中文参考样例。
- 删除模板中的 Front Matter、占位符和无内容章节。
- 更新资源清单、校验器和安装验收，使其验证样例结构而不是渲染字段。

## 验证证据

| 检查项 | 预期结果 |
|---|---|
| 搜索 `.tmpl` | 模板目录无匹配文件 |
| 搜索双花括号变量 | 模板目录无匹配内容 |
| 中文结构检查 | 所有样例使用中文标题和说明 |
| 安装验收 | Codex 与 Claude Code 均安装同一套固定参考文件 |

## 预防与演进候选

新增参考资料时先确认使用者是 Agent 还是渲染器。只有真实运行时需要插值时才引入变量；仅供阅读和仿写的资料必须提供完整样例。
