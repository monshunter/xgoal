# autogo-rally

> 无用之用：不是因为容易才继续，而是通过继续调查让问题变得清楚。

## 目标

打断可观察的停滞、回避和过早终止，把当前工作重新收敛到下一项最小可验证行动。本 Skill 不假设 Agent 具有真实情绪，也不改变当前目标、风险或工作流权限。

## 输入与发现

- 当前目标、批准范围和完成标准
- 最近两次行动、失败结果以及新产生或缺失的 Evidence
- 可继续检查的代码、日志、测试、文档和运行状态
- Human Gate、安全边界、权限、必要信息和外部系统状态

## 输出与持久制品

- 一句短促鼓励
- 一项立即执行的最小可验证行动
- 该行动产生的新 Evidence，或经过验证的真实 Blocker

不创建持久制品，不单独维护状态，不取代 Progress、Plan、Spec 或 Journal。

## 副作用与 Human Gate

- 类型：Recovery Micro-Skill
- 风险：只读，不产生项目副作用
- 副作用：无
- Human Gate：无
- 默认调用者：其他 Skill 或原生 Agent

不得用本 Skill 掩盖安全拒绝、用户必须决定的产品语义、生产/数据/Secret/权限/不可逆操作的 Human Gate、无法自主取得的必要信息、确认后的外部系统故障、用户明确暂停或当前范围已经完成。

## 执行步骤

1. 检查停止原因是否属于 Human Gate、安全边界、权限不足、必要信息缺失、外部系统故障或当前范围已完成。属于真实边界时不触发 Rally，按正常 Blocked 或 Close 流程处理。
2. 只输出一句短促鼓励。优先运行：

   ```bash
   python3 .agents/skills/autogo-rally/scripts/rally.py
   ```

   需要指定语气时使用 `--category engineering|sunzi|playful|calm`；需要标签时使用 `--prefix`。脚本不可用时直接输出一句等价短句，不因此阻塞。
3. 将模糊的“做不到”改写为已知事实、未知项、当前假设和真实阻塞条件。
4. 选择能够产生新 Evidence 的最小行动，例如读取一段代码、检查一条日志、运行一个聚焦测试、构造最小复现或验证一个假设。
5. 立即执行该行动，不只宣布下一步。当前路径再次失败时必须改变策略或调查入口，禁止原样机械重试。
6. 用新 Evidence 返回原工作流；若行动证明存在真实 Blocker，则记录证据和解除条件并正常停止。

## 验证与完成

- 已先排除真实 Blocker 和 Human Gate
- 鼓励信息只有一句，没有扩展为冗长说教
- 已实际执行下一项最小可验证行动
- 本轮产生了新 Evidence、缩小了未知范围，或证明了带解除条件的真实 Blocker
- 当前目标、风险、权限和完成标准均未被 Rally 改写

## 失败、重试与幂等

同一次停滞只需触发一次；重复输出鼓励但不执行行动不算推进。辅助脚本失败时直接使用一句短句并继续。相同失败再次出现时更换假设、观测面或实现路径；若没有任何可替代路径，回到正常调查或 Blocked 流程，不伪造可继续性。
