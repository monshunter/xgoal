# autogo-instruction-resolve

## 目标

根据真实受影响路径，按根到局部的顺序解析必须加载的项目指令文件，避免遗漏局部约束或加载无关规则。

## 输入与发现

- 项目根目录
- 一个或多个受影响文件或目录，包括尚未创建的新文件路径
- 当前 Agent 的 `AGENTS.md` 文件名

## 输出与持久制品

- 按根到局部排序、去重后的有效指令文件列表
- 可选 JSON：每个输入路径的规则链及合并后的有效规则列表

不创建持久制品。

## 副作用与 Human Gate

全程只读文件系统，不修改项目状态，不需要 Human Gate。

## 执行步骤

1. 确认项目根和真实受影响路径；不要用目录猜测代替影响范围判断。
2. 优先运行 Skill 自带脚本：

   ```bash
   python3 .agents/skills/autogo-instruction-resolve/scripts/resolve_agents.py --root . path/to/file path/to/directory
   ```

   需要机器可读结果时增加 `--json`。
3. 按输出顺序读取全部指令文件；根规则先加载，较近组件规则在其范围内补充或收窄。
4. 路径变化后重新解析，不沿用旧路径得到的规则链。

## 验证与完成

- 每个输入路径都位于项目根内
- 输出只包含实际存在的 `AGENTS.md`
- 顺序为项目根到最近局部组件，重复文件已去除
- 新文件路径按其父目录继承规则

## 失败、重试与幂等

缺少根指令文件或路径逃逸项目根时明确失败，不返回部分真相。点号目录可能被误判为文件时，由调用者显式传入父目录。相同根目录、路径和文件状态必须产生相同结果。
