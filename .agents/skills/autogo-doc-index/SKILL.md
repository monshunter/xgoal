# autogo-doc-index

## 目标

从当前 docs 文件重建工作区索引，只更新 Agent 托管区块并保留项目已有内容。此 Skill 只负责索引投影，不决定工作区或文档是否应当存在。

## 输入与发现

- 项目根目录
- 一个或多个已初始化 docs 工作区，或 `--all`
- 工作区中的 Markdown 文件名、一级标题和现有 `INDEX.md`

## 输出与持久制品

- 更新后的 `INDEX.md` Agent 托管区块
- 每个已处理工作区及收录文档数量的命令输出

## 副作用与 Human Gate

只有索引更新属于已授权 docs 变更的必要收口，或用户已明确授权更新索引时才写入。只读检查未授权修改时只报告漂移，不运行重建。写入时仅修改明确选中的 docs 工作区索引，不得创建未授权工作区或具体任务文档；不需要 Human Gate。

## 执行步骤

1. 确认项目根、受影响文档和对应已初始化工作区。
2. 优先运行 Skill 自带脚本：

   ```bash
   python3 .agents/skills/autogo-doc-index/scripts/build_index.py --root . docs/specs
   ```

   需要更新全部已有工作区时使用 `--all`。只有已明确允许创建缺失索引时才使用 `--create`。
3. 脚本不可用时，直接读取稳定文件名和一级标题，等价更新 `<!-- AGENT-HARNESS:BEGIN INDEX -->` 托管区块。
4. 检查 Diff，确认项目自有内容、README 和非托管区块未被覆盖。

## 验证与完成

- 索引条目与当前文档一一对应
- ID、标题和相对链接来自当前文件名与一级标题
- 重复运行不产生额外 Diff
- 未创建不属于当前范围的工作区或任务文档

## 失败、重试与幂等

缺少工作区或 `INDEX.md` 时停止并说明应先由哪个流程初始化，不默认使用 `--create`。文档缺少一级标题时使用文件名作为标题。相同输入重复执行必须得到相同托管区块。
