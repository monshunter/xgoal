# Architecture 工作区

## 目的

保存满足 Spec 的系统方案、组件边界、契约、状态、失败恢复与迁移设计。

## 制品与命名

- 设计文档使用 `DESIGN-<编号>.md` 或稳定的领域文件名。
- 身份、状态和替代关系沿用项目既有文档约定；没有既有约定时保持最小结构。
- 只保存跨组件或需要长期维护的架构事实；一次性探索不在此固化。

## 生命周期与归档

只在设计需要长期维护时创建或更新；旧文档按项目既有生命周期保留替代关系，不为统一格式批量收编。

## 负责的 Skills

`autogo-solution-design`、`autogo-design-review`。

## INDEX 维护

Agent 在设计状态变化后同步维护 `INDEX.md`。
