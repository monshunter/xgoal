# Decisions 工作区

## 目的

保存具有长期影响、存在真实取舍且难以逆转的架构决策记录。

## 制品与命名

- ADR 使用 `ADR-<编号>.md`，记录上下文、选择、替代方案和后果。
- 普通实现细节不升级为 ADR。

## 生命周期与归档

使用 `draft → review → approved/active → superseded`；不得无痕删除历史决策。

## 负责的 Skills

`autogo-solution-design`、`autogo-design-review`。

## INDEX 维护

Agent 在 ADR 新建、批准或被替代后同步维护 `INDEX.md`。
