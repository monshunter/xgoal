# Specs 工作区

## 目的

保存可审阅、可验收的行为与质量契约。

## 制品与命名

- 正式制品使用 `SPEC-<编号>.md` 或项目已有稳定领域文件名，并记录稳定 AC ID。
- 身份、状态和替代关系沿用项目既有文档约定；没有既有约定时保持最小结构。
- 只在行为合同需要跨实现长期存在时创建或更新，已有代码、测试或契约足够时不制造重复 Spec。

## 生命周期与归档

沿用项目既有生命周期；被替代内容保留新 owner 指向，不为统一格式批量迁移。

## 负责的 Skills

`autogo-spec-write`、`autogo-spec-review`。

## INDEX 维护

Agent 在创建、更新或归档 Spec 后同步维护 `INDEX.md`。
