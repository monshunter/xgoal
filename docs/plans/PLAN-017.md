# PLAN-017：目标驱动的验收准备与自主交付

目标：新项目只提供目标、硬约束和必要环境授权即可规划、准备验收、实施和验证；已有脚本或 Markdown 验收材料优先采用。

范围：验收输入、规划产物、生成验证器的信任与持久化、执行和恢复、状态反馈、默认配置和实际新项目验收。复用现有 Kernel 状态与 Evidence，不增加顶层编排系统，不自动开放网络、Secret、发布或生产权限。
