# PLAN-014：完成受信环境与场景验收链路

目标：从项目配置驱动环境准备、服务就绪、真实场景、业务断言和资源清理，并支持按需的 Agent 辅助验收。

范围：现有 Local Environment Provider 的服务生命周期接入、场景与 Validator 关联、验收制品、可选验收会话及失败恢复；不增加存储后端或更改确定性完成权威。

## Phase 1：受信环境

- [ ] 1.1 为服务及其就绪检查建立受信配置和依赖顺序。
- [ ] 1.2 贯通验证前准备、服务启动、就绪、停止与崩溃后归属恢复。
- [ ] 1.3 保存 bootstrap 和服务诊断，验证启动失败、超时、取消和资源清理。

## Phase 2：场景验收

- [ ] 2.1 建立验收目标、场景、Validator 与制品的关联，并让 Planner 获得真实验证能力说明。
- [ ] 2.2 实现可选独立验收 Agent 会话，限制源码写入和完成权威，并接入事实验收与阻塞处理。
- [ ] 2.3 完成具有实际服务、客户端交互和业务断言的 E2E 场景，验证错误结果不能晋升或完成。

## Phase 3：收口

- [ ] 3.1 完成环境与验收集成回归、Change Review、文档对账和提交。
