- 配置、公开协议、领域状态、API/CLI、Completion、Final Report 和 Benchmark 不再含模型 Budget、Token/费用、余额或账单字段。
- SQLite migration `0007_remove_model_accounting.sql` 在升级时删除早期草案表；历史 migration 保持不可变以继续检测 drift，最新 Schema 测试确认两张旧表不存在。
- Codex/Claude fixture 注入供应商原始 usage/cost 字段，Adapter 测试确认字段在持久化前丢弃。
- xgoal 仍保留逐调用超时、输出字节上限、进程取消、单写并发、Lease Heartbeat 与无进展判定；这些是执行安全边界，不参与模型核算或 Completion。
