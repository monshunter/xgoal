# Operations 工作区

## 目的

保存环境、部署、运行、恢复、清理和故障处置的长期操作知识。

## 制品与命名

- Operation 使用 `OP-<编号>.md` 或稳定的系统/环境名称。
- 必须写明前置条件、风险、验证、失败处理、回滚与最终状态。

## 生命周期与归档

使用 `draft → review → active → superseded/archive`；过期命令必须显式标记。

## 负责的 Skills

`autogo-env-manage`、`autogo-deploy`、`autogo-investigate`。

## INDEX 维护

Agent 在操作合同或适用环境变化后同步维护 `INDEX.md`。
