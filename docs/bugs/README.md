# Bugs 工作区

## 目的

保存可复现缺陷、影响、根因、修复边界、回归证据与恢复结果。

## 制品与命名

- Bug 使用 `BUG-<编号>.md`，记录稳定复现条件和实际 Evidence。
- 普通主动维护不强制创建 Bug；不得为流程完整而制造占位记录。

## 生命周期与归档

使用 `open → investigating → fixed → verified/closed`；误报或重复项保留关联说明。

## 负责的 Skills

`autogo-bug-report`、`autogo-investigate`、`autogo-tdd`。

## INDEX 维护

Agent 在 Bug 状态变化后同步维护 `INDEX.md`。
